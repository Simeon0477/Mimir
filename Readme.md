# **Projet MIMIR**

## **Système d'analyse de données, moteur de règles et Machine learning**

### 1- **Objectif général**
Développer  une bibliothèque python permettant de :
 - Charger, nettoyer et analyser des données structurées
 - Appliquer un moteur de règles métier flexible et extensible
 - Entraîner deux modèles de Machine Learning codés manuellement
 - Piloter l'ensemble des fonctionnalités via une interface en ligne de commande intuitive
